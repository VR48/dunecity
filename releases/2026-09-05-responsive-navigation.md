# DuneCity 1.0.534 / Android 0.2.23

## Responsive Navigation And Credits

- Restore both 4:3 and 16:9 logical interface choices on Android while keeping
  interface scale independent from the device's physical resolution.
- Keep the classic Dune II menu presentation as the default and improve its
  button geometry at low resolutions. Preserve Enlarged mode for Android TV,
  tablets, foldables, and farsighted players.
- Group Single Player, Multiplayer, Map Editor, and Mods under Modes so the
  main menu remains orderly. Show How To Play only for DuneCity and Dune2R
  Assets only for Dune2R.
- Replace the fixed About artwork with a readable, scrollable credits page.
  Credit Stefan van der Wel as creator of Dune Legacy and DuneCity; credit
  Vukasin Ristic as Dune Legacy repository maintainer, DuneCity maintainer and
  gameplay developer, and creator of Dune2R.
- Add the verified local Windows and Android build guide, including warm-cache
  and exFAT workarounds for the PREDATOR build host.

These changes are presentation-only and do not alter gameplay rules, save data,
multiplayer protocol, QuantBot, or the private QBot simulator.
