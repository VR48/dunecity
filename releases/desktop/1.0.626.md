# Dune City 1.0.626

Changes since 1.0.612:

- Add road upkeep at Micropolis's default rate: 0.7 credits per road tile per city year, with heavy-traffic roads counting double. Roads are free below 2,000 displayed population for each house; the exemption returns if population falls below that threshold. The budget shows road costs, and automatically built roads now record their owner.
- Reduce police reinforcements to three troopers and one trike. Existing cooldowns and unit limits remain. Improve police placement to favour underserved areas instead of clustering stations.
- Generate traffic from successful, occupancy-based journeys with Micropolis-style decay and light/heavy display thresholds, reducing the excessive traffic generated by tiny settlements.
- Let residential lots gain or lose individual houses before becoming apartments. Bring across additional residential, commercial and industrial models, plus building and traffic animations.
- Correct city labour demand and unemployment calculations, consider pollution and land suitability before zoning, and improve residential/commercial/industrial construction priorities. Windtraps count as light industry, including their sidebar label.
- Add a pollution overlay and civic demand notices for airports, starports and stadiums. Use scaled Micropolis park terrain for turret land-value effects.
- Replace expensive city placement connectivity searches with local access checks, reuse road foundations and spare lanes, and bound repeated placement work. Improve performance diagnostics for future game analysis.

Older saves remain readable. New house occupancy data requires this version for newly saved games; all multiplayer participants should use the same version.

Local macOS validation: 536 tests passed; three optional tests skipped. Desktop packages are published only after the release workflow's tests and Windows, macOS and Linux builds succeed.
