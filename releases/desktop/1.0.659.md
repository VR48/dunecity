# DuneCity 1.0.659

Play online across the browser and desktop through the public lobby. Choose a player name, join a public game without a code, or host a private game with an invitation. Public-lobby chat is available after confirming your name.

- Adds HTTPS crossplay on the existing game server, with encrypted browser and desktop connections and recoverable join errors.
- Makes the public Join Game button easier to find, allows changing a confirmed name, and explains duplicate-name refusals.
- Restricts lobby edits to the appropriate player, validates network commands and bounds relay traffic and queues.
- Fixes browser widescreen and resolution changes, adds more resolutions and uses a larger desktop default.
- Records browser/native participation in backward-compatible server analytics.

Existing desktop LAN and direct Internet multiplayer remain available. Crossplay players should use this version on both browser and desktop. Relay recovery restores the service after a crash; it does not resume a match interrupted by a server restart.
