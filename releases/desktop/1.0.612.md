# Dune City 1.0.612

Changes since 1.0.608:

- Keep qBot factory and refinery exits connected to open ground. Later buildings and MCV deployments respect escape lanes, including other construction yards' reserved sites, so rear factories are less likely to trap their own units. This prevents new blockages; existing sealed courtyards are not automatically demolished.
- Give successful unit types more weight in qBot production ratios using full-match damage value, kill bonuses and losses. Keep opening exploration and existing composition safeguards.
- Randomise attack intervals consistently for every house, removing a permanent house-based timing bias. Scheduling uses deterministic simulation inputs for multiplayer.
- Reduce repeated searches during police and turret placement planning.
- Fix empty qBot harvesters repeatedly returning to refineries when their previous spice destination is unsafe. Preserve valid unloading trips and deliberate safety holds.
- Restore automatic harvester restart for Original and Smart AI, which depend on the native restart behaviour. Human stop orders remain respected.

The qBot movement, placement and production improvements apply to both Vanilla and Dune City. City service planning applies to Dune City.

Harvester maximum overrides remain supported. The spice-based harvester target formula is unchanged in this release.

Older saves remain readable. Multiplayer participants must use the same version. Local validation: 504 tests passed, with three optional tests skipped.
