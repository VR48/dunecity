# Dune City 1.0.601

- Fix a squad-controller crash when a target has been destroyed.
- Gather armies in reachable clearings with enough room for the force. Blocked
  destinations no longer send everyone onto the same rally tile.
- Keep the main body advancing while stragglers catch up, preserve shared attack
  targets, and measure stalled movement instead of cancelling advancing waves.
- Add the 4-player DuneCity (192x192) and 4 corners (128x128) default maps.
- Fix non-finite mod configuration validation in macOS Release builds.
- Require passing tests and Windows, Linux and macOS builds before publication.

Includes the Windows compatibility fix for the unpublished 1.0.600 build.
Older saves remain readable. Multiplayer participants must use the same version.
