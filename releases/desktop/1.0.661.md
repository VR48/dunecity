# Dune City 1.0.661

Browser and desktop players can now meet through Play Online, browse public games, host private games with invitations, and use the shared lobby chat after confirming a player name. Public games join directly from the list without a code.

This release also hardens network parsing and lobby permissions, adds browser/native classification to compatible match logging, improves browser display and resolution settings, and paces relay traffic to prevent polling backlog disconnects.

The HTTPS polling path uses a bounded startup command allowance to reduce lockstep stutter. In public browser/browser and browser/desktop tests, rendering remained around 60 FPS and simulation improved from roughly 37–42 to 56–57 updates per second on the test connection. Polling still adds command delay and can pause during latency spikes; these measurements are not a guarantee for every connection or game speed. Desktop ENet and WebSocket sizing keep their previous behavior.

Use the same game version and bundled mod/content on both clients. Browser multiplayer is available from the Play Online page once its separate deployment completes.
