# Dune City 1.0.630

Changes since 1.0.626:

- In Dune City, reuse roads built by any house for construction access and prepared foundations. Enemy and abandoned roads no longer stop expansion; terrain, occupied buildings and local road-access checks still apply. Road upkeep ownership is unchanged.
- Fix QuantBot ornithopter production being starved by carryall and ground-unit orders. After the first carryall, an affordable unmet air target receives priority over additional carryalls; existing unit caps and prerequisites still apply.
- Make adaptive harvester targets less conservative by reducing the spice budget per worker by 25%. This raises the spice-based target by about one third where other limits allow, while retaining the lobby limit, refinery throughput and affordability checks.
- Build QuantBot repair yards earlier once a heavy factory and refinery are operational, and scale baseline repair capacity with army value within the existing yard cap.
- Fix a repair-yard crash after nuclear explosions destroyed stored units at stale map positions. Nuclear damage now excludes inactive cargo, and repair yards safely clear missing occupants.

These changes apply to Dune City and Vanilla where relevant; shared road access is specific to Dune City. The save layout is unchanged from 1.0.626. All multiplayer participants should use the same version.

Validation: 547 tests passed locally; three optional tests skipped. Local dependency audits passed. Remote publication is gated on Linux tests and Windows, macOS and Linux builds.
