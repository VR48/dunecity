# Dune Legacy Android 0.2.24

Android ARM64 release based on the DuneCity 1.0.535 payload.

## Included

- Dedicated, consistently spaced Dune2R zoom and graphics-mode controls.
- Existing classic and enlarged menu modes, widescreen choices, foldable
  handling, and downloadable Dune2R asset support.

## Package

- Application ID: `net.dunecity.dune2r`
- Version name: `0.2.24`
- Version code: `1000544`
- Asset: `DuneLegacy.apk`

Existing saves and configuration are preserved during upgrade. Optional Dune2R
remastered artwork remains downloadable in-game and is not embedded in the APK.
