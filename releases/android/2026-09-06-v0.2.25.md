# Dune Legacy Android 0.2.25

Android ARM64 release based on the DuneCity 1.0.536 payload.

## Included

- Stefan van der Wel's latest published DuneCity rendering and settings fixes.
- Improved QuantBot construction-yard planning, city zoning, heavy-unit
  production, strategic reserves, and repair-yard capacity.
- Correct zone ownership after loading saves and safer civic-zone placement.
- Existing classic/enlarged menus, foldable handling, and downloadable Dune2R
  asset support.

## Package

- Application ID: `net.dunecity.dune2r`
- Version name: `0.2.25`
- Version code: `1000545`
- Asset: `DuneLegacy.apk`

Existing saves and configuration are preserved during upgrade. Optional Dune2R
remastered artwork remains downloadable in-game and is not embedded in the APK.
