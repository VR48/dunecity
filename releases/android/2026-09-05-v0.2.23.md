# Dune Legacy Android 0.2.23

Android ARM64 release based on the DuneCity 1.0.534 payload.

## Included

- Standard 4:3 and widescreen 16:9 interface choices at each supported logical
  interface size.
- Improved classic and enlarged start-menu sizing for phones, tablets,
  foldables, Android TV, and accessibility use.
- A grouped Modes menu with context-specific DuneCity and Dune2R controls.
- A scrollable About page with corrected project creator and maintainer roles.
- Existing landscape, fold/unfold, touch, mouse, controller, and Android
  Back/Escape handling.

## Package

- Application ID: `net.dunecity.dune2r`
- Version name: `0.2.23`
- Version code: `1000543`
- Asset: `DuneLegacy.apk`

Existing saves and configuration are preserved during upgrade. Optional Dune2R
remastered artwork remains downloadable in-game and is not embedded in the APK.
