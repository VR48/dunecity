# DuneCity Android 0.2.16

- Makes the SDL activity explicitly resizable for foldables, DeX, and Android multi-window use.
- Removes the fixed landscape manifest restriction that could trigger foldable compatibility mode.
- Handles density and large-screen configuration changes without restarting the native game.
- Uses the active SDL window size to keep menus readable on unfolded high-resolution displays.
- Adds window, dp, density, and orientation telemetry for device-specific diagnostics.
