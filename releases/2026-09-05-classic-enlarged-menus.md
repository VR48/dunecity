# DuneCity 1.0.533 / Android 0.2.22

## Classic and Enlarged menus

- Restores the original centered Dune II start menus as the default on fresh installations.
- Adds an explicit Classic / Enlarged selector to the main-menu Display screen.
- Adds the same persistent Menu Layout selector under Options > Display.
- Keeps the enlarged two-column layout available for Android TV, tablets, foldables, and farsighted players.
- Keeps interface resolution and Desert Gold / High Contrast colors independent from menu layout.
- Preserves the Dune2R Assets control as a Dune2R-only menu item in both layouts.
